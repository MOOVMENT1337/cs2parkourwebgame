# Открытые вопросы перед началом кода

## Уже решено

- Основная платформа — актуальный desktop Google Chrome.
- Утверждён TypeScript/pnpm/Vite/React/Three.js/Rapier/Fastify/PostgreSQL.
- Bunnyhop автоматический при удержании клавиши прыжка.
- MVP полностью single-player, без real-time multiplayer.
- Есть soft currency и demo top-up без настоящего платежа или списания денег.

## Выбранный путь для точной физики

Так как конкретный сервер не предоставлен, разработка начата с собственного версионированного профиля `community-autobhop-surf-v0`.

- Текущие значения нужны для прототипирования и не считаются доказанным совпадением с CS2.
- Для калибровки всё ещё желательны название/адрес эталонного сервера, карта и dump movement cvars.
- Если конкретного сервера не появится, comparative traces будут собираться на собственной зафиксированной конфигурации CS2 community auto-bhop/surf.

## Важные, но не блокирующие прототип движения

- Нужны ли приседание, crouch-jump, лестницы и moving platforms в первой версии?
- Насколько близко по ощущениям к CS должно быть базовое движение: узнаваемое направление или измеряемая настройка под конкретный эталон?
- Какие assists кроме утверждённого auto-bhop допустимы: траектория, подсветка правильного угла стрейфа, сохранение на checkpoint?
- Награда зависит от первого прохождения, времени, сложности, ежедневных целей или их комбинации?
- Что делать с дубликатами косметики?
- Какие предметы видит игрок в первом лице: перчатки, нож, trail, часы, HUD theme?
- Есть ли готовые собственные ассеты/карты или весь контент создаётся с нуля?
- Где предполагается первый деплой и нужна ли авторизация через Steam/Discord/Google позже?

## Текущий статус

Создан build 0.4 технического прототипа с полноценным frontend shell, каталогом из 22 ножей и 8 комплектов рук/перчаток, CT-viewmodel с синхронными ножевыми анимациями, соревновательным HUD и облегчённой трассой. Следующая точка принятия решения — снять CS2 traces и заменить предварительные параметры профиля измеренными значениями.
