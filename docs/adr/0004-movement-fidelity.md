# ADR-0004: Проверяемое соответствие движению CS2

- Статус: принято
- Дата: 2026-09-15

## Контекст

Сходство с CS2 bhop/surf movement — главный критерий качества. Настройки community-серверов различаются, а открытый Source SDK 2013 не является исходным кодом Source 2.

## Решение

Не настраивать движение «на глаз». Сначала выбрать конкретный актуальный CS2 server profile, получить сравнительные traces на эквивалентной test gym и заранее определить допустимые отклонения. Реализация считается готовой только после comparative и golden replay tests.

Полная методика описана в `docs/MOVEMENT_FIDELITY.md`.

## Последствия

- Выбор эталонного server profile блокирует финальную фиксацию physics constants.
- Старые Source-алгоритмы можно изучать как исторический контекст, но нельзя выдавать их за точную реализацию CS2.
- Изменение movement preset создаёт новую версию результатов и leaderboard.
