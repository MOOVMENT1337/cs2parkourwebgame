# ADR-0005: Фиксированные часы симуляции build 0.1

- Статус: принято для прототипа
- Дата: 2026-09-15

## Контекст

Физика не должна меняться вместе с частотой рендера Chrome. Одновременно окончательное соответствие subtick-поведению CS2 ещё не измерено.

## Решение

- Симуляция build 0.1 выполняется с fixed timestep 64 Hz.
- Three.js render loop запускается только через `renderer.setAnimationLoop`.
- Накопитель времени отделяет simulation steps от кадров рендера.
- Frame delta ограничивается 100 ms, чтобы возврат из зависшей/фоновой вкладки не создавал spiral of death.
- Скрытая вкладка останавливает render loop и снимает Pointer Lock.

## Последствия

Частота 60/120/144 Hz влияет на плавность отображения, но не на формулы движения. Значение 64 Hz считается предварительным и может измениться новой версией movement profile после сравнительных замеров CS2.
