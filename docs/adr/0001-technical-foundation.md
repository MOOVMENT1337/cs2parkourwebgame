# ADR-0001: Техническая основа

- Статус: принято
- Дата: 2026-09-15

## Контекст

Нужна браузерная 3D-игра с точным контроллером движения, UI-оболочкой, backend-экономикой и повторным воспроизведением попыток на сервере.

## Решение

Использовать TypeScript monorepo с pnpm workspaces. Клиент строится на Vite, React используется для shell/HUD, Three.js — для императивного 3D-runtime, Rapier — для collision queries. Backend — модульный монолит на Fastify и PostgreSQL; run verifier — отдельный процесс с общим movement package.

## Последствия

- Одинаковые типы и movement logic можно использовать в браузере и verifier.
- React не участвует в покадровом обновлении физики.
- Rapier не определяет правила движения; CS2-style controller остаётся собственной доменной логикой.
- Версии зависимостей фиксируются при создании workspace.
