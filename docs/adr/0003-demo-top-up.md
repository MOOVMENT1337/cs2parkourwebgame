# ADR-0003: Демонстрационное пополнение валюты

- Статус: принято
- Дата: 2026-09-15

## Контекст

Нужно проверить UX магазина и экономический ledger без подключения реальных платежей.

## Решение

Добавить demo top-up с фиксированными пакетами тестовой валюты. Интерфейс показывает этапы выбора, обработки и успеха, но явно маркирует демонстрационный режим и отсутствие списания. Банковские данные не собираются, платёжный провайдер не вызывается.

Backend начисляет валюту идемпотентной операцией ledger с причиной `demo_top_up`. Возможность защищена environment feature flag и rate limit.

## Последствия

- Можно проверить магазин, баланс, кейсы и обработку сетевых повторов.
- Demo top-up не является заготовкой настоящей платёжной интеграции.
- Настоящие платежи потребуют нового ADR, юридической проверки, отдельной модели payment state и webhook processing.
