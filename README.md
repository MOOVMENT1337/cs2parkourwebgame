# Parkour Flow (рабочее название)

Браузерная first-person parkour-игра с точным управлением, стрейфами, bunnyhop- и surf-картами. Игрок проходит трассы, улучшает результат, получает внутриигровую валюту и открывает косметические предметы.

Проект вдохновляется ощущением движения соревновательных FPS. Для локального прототипа подключены разрешённые владельцем проекта модели ножей, рук и перчаток; происхождение и условия распространения зафиксированы рядом с ассетами.

## Текущий статус

Работает локальный frontend vertical slice: главное меню, процедурная bhop/surf-трасса, fixed-step movement runtime, каталог из 22 ножей и 6 комплектов рук/перчаток, соревновательный HUD, таймер, чекпоинты и экран паузы. Backend, реальные аккаунты и экономика пока остаются следующими этапами.

До заявления о точном соответствии физики нужно выбрать конкретную конфигурацию CS2-сервера, которая станет измеряемым эталоном движения.

## Утверждённые решения

- Главная целевая платформа MVP — актуальный desktop Google Chrome.
- Игра остаётся single-player; real-time multiplayer не разрабатывается.
- Bunnyhop срабатывает автоматически, пока игрок удерживает клавишу прыжка.
- Добавляется явно обозначенное демонстрационное пополнение: реальной оплаты и списания денег нет, тестовая валюта начисляется через backend ledger.
- Техническая основа: TypeScript, pnpm workspace, Vite/React, Three.js, Rapier, Fastify и PostgreSQL.
- Точность движения проверяется сравнительными сценариями, описанными в [спецификации соответствия движению](docs/MOVEMENT_FIDELITY.md).

## Главный принцип разработки

Сначала должен появиться небольшой, но качественный вертикальный срез: одна bhop-карта, одна surf-секция, таймер, рестарт и стабильное движение. Аккаунты, кейсы и большой каталог контента подключаются только после подтверждения, что основной игровой цикл действительно приятен.

## Запуск текущего прототипа

Требуется Node.js 22.12+ и pnpm 11.19+.

```bash
pnpm install
pnpm dev
```

Открыть `http://127.0.0.1:5173` в актуальном desktop Chrome. Управление: `WASD`, мышь, удержание `Space` для auto-bhop, `R` для рестарта, `N` для перехода к следующему чекпоинту во время тестирования, `F3` для диагностического HUD, `Esc` для паузы.

## Реализовано в build 0.3

- Vite/React shell и лениво загружаемый Three.js/Rapier runtime.
- Fixed simulation loop 64 Hz независимо от частоты рендера.
- Версионированный предварительный movement profile.
- Ground acceleration, friction, air acceleration и auto-bhop.
- Capsule collision, step-up, ground snap и slope/surf sliding.
- Процедурная test gym с bhop-платформами и surf-рампами.
- Облегчённая учебная геометрия, три чекпоинта и возврат на последний из них после падения.
- Главное меню с каталогом карт, экраном снаряжения, заготовкой кейсов и настройками.
- 22 импортированные модели ножей и 6 текстурированных комплектов рук/перчаток с мгновенным выбором в инвентаре и ленивой загрузкой только активных моделей.
- Три тестовые отделки импортированных ножей и процедурный резервный viewmodel на случай ошибки загрузки ассета.
- Отдельный render pass для FPS-viewmodel: геометрия карты не может перекрыть руки или нож.
- Настоящие steep surf-плоскости выше walkable-порога с сохранением касательной скорости.
- HUD с компоновкой соревновательного FPS: радар, прогресс и таймер, здоровье/броня/баланс, скорость, активный нож, локальный best time и отдельный диагностический режим.
- Unit tests базовых формул и детерминированности input trace.

Текущий профиль `community-autobhop-surf-v0` — калибровочный, а не заявление о завершённом совпадении с CS2. Импортированные ассеты перечислены в [`NOTICE.md`](apps/client/public/assets/viewmodels/cs2/NOTICE.md) и локальном manifest; остальная процедурная графика и интерфейс прототипа оригинальные.
